# vpn-sub 📡

**دریافت کانفیگ‌های سریع و جدید برای عبور از تحریم اینترنت.**

یک سرویس کاملاً خودکار که لینک‌های کانفیگ V2Ray، Vmess، Vless و Trojan را از کانال‌های تلگرام استخراج کرده و به‌صورت یک فایل اشتراک (Subscription) آماده‌ی استفاده منتشر می‌کند.

---

## ⛔ توجه

این لیست کانفیگ‌ها از میان کانفیگ‌های موجود در اینترنت جمع‌آوری شده است. این کانفیگ‌ها فقط برای دسترسی آسان‌تر در این مخزن نمایش داده می‌شوند و من هیچ مسئولیتی در قبال آن‌ها ندارم.

کانفیگ‌ها به‌صورت خودکار از کانال‌های تلگرام زیر استخراج می‌شوند:

- `@V2ray_Alpha`
- `@free1_vpn`
- `@v2ray_free_conf`
- `@vlessrus`
